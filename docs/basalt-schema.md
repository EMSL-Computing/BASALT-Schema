
The Basalt Schema is a [LinkML](https://linkml.io)-based data model for
MONet soil analysis data management. It defines the canonical structures for samples,
processed data products, site metadata, and enrichment providers used by Basalt.

**Repository:** [pnnl/analysis-api](https://github.com/pnnl/analysis-api)  
**Canonical URI:** <https://w3id.org/MONet/basalt-schema>

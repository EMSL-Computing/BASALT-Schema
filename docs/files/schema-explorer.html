How to explore

This map lays out the whole active schema as a left-to-right flow. Colour = inheritance family / process stage.

  • Click any box (or sidebar entry) to select a class — its inheritance ancestors light up and its slots appear here.
  • Hover a slot for its range, pattern, and description.
  • Highlight a workflow set (e.g. AMP2) to see every class it touches across the flow.
  • Follow references: class-typed slots become clickable jumps.

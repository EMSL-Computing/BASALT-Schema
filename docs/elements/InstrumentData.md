

# Class: InstrumentData 


_An abstract parent class for raw data files generated by different kinds  of instruments. All subclasses must have a slot pointing upstream that  specifies the analysisActivity subclass which created them._




* __NOTE__: this is an abstract class and should not be instantiated directly


URI: [basalt_schema:InstrumentData](https://w3id.org/MONet/basalt-schema/InstrumentData)
